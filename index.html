Required: symbol, close, prev_close, volume, avg_volume_20. Other fields optional. news_sentiment must be manually verified and set to -1, 0 or 1. asof is the snapshot date (YYYY-MM-DD).

How this V1 works

Signal score (0–100): 50 base + up to 20 for daily price change, up to 15 for volume relative to 20-day average, up to 10 for manually verified news sentiment, and up to 5 for positive EPS; optional high debt-to-equity or high P/E reduces the score. Missing optional fields are neutral, not assumed positive.

Important: One-day change is not an advance breakout prediction. A 3–10 day outlook requires more historical OHLCV data, backtesting, and validated news. V1 therefore does not invent entry, target, stop loss or future return.

Upgrade path: A future secure backend can connect authorized data feeds, a scheduled daily job, verified announcement ingestion, AI summaries, notifications and backtests. API secrets must never be embedded in public GitHub Pages code.

Free hosting: GitHub Pages can host this static app. Data stays in this browser's local storage; it is not synced to other devices. For installation support, open over HTTPS and use Chrome's Add to Home screen if offered.
